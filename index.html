AquaPulse is a Smart IoT Fish Feeder designed to address the critical challenges facing smallholder aquaculture in East Africa. By combining an affordable ESP32 microcontroller with a Firebase-connected web dashboard, real-time ultrasonic hopper monitoring, and offline-first RTC scheduling, AquaPulse delivers precise, automated feed dispensing that reduces waste by up to 30% and eliminates the need for daily dawn/dusk site visits.

Problem Statement

Smallholder fish farmers in Uganda face four interconnected challenges that stifle productivity and profitability:

  • Inconsistent Manual Feeding: Irregular feeding schedules stunt Nile Tilapia growth and stagger overall aquaculture yields.
  • Feed Waste: Wasted feed accounts for up to 30% of operating expenses due to wind drift and over-application.
  • Prohibitive Costs: Existing commercial automated feeders are imported and priced at $300–$1,500+, putting them out of reach for local smallholders.
  • No Remote Telemetry: Smallholders have no affordable, remote telemetry system to schedule feeds and monitor feed levels from their phones.

Project Objectives

  • Affordable Hardware: Design an affordable, locally-sourced automated fish feeder using a standalone ESP32 DevKit.
  • Web Dashboard: Build a web-based dashboard synced via Firebase Firestore for remote management and telemetry.
  • Offline Resilience: Implement an offline-first scheduling fallback using a DS3231 RTC module to ensure feeding during WiFi drops.
  • Power Isolation: Ensure hardware resilience by isolating high-current stepper motor rails to avoid ESP32 brownouts.

Project Design

The AquaPulse system architecture centers on a standalone ESP32 DevKit that serves as both the hardware controller and WiFi communication hub. The design eliminates the need for a secondary microcontroller, reducing cost and serial communication lag that plagued earlier dual-board prototypes.

Key Design Decisions:
• Standalone ESP32: Single MCU handles sensor reading, motor control, LCD display, and Firebase communication.
• Isolated Power Rails: The 28BYJ-48 stepper motor draws current from a separate 5V rail to prevent ESP32 brownouts.
• Voltage Divider: A 1kΩ/2kΩ resistor divider on the HC-SR04 ECHO pin safely steps 5V down to ESP32-compatible 3.3V.
• Offline-First RTC: The DS3231 module maintains local time and triggers scheduled feedings even during WiFi outages, caching events for upload upon reconnection.

System Prototype & Assembly

The physical prototype integrates all components onto a custom enclosure mounted above the fish pond. The hopper holds feed pellets and the stepper-driven auger dispenses precise portions at scheduled intervals.

Assembled AquaPulse prototype unit

Hopper Telemetry: Real-time ultrasonic depth sensing maps the hopper capacity (e.g., 78% full) onto both the I2C LCD and the Firebase Firestore database, giving farmers instant visibility into feed levels from anywhere.

Power Spike Mitigation: Separating the stepper motor's power path from the ESP32's power supply completely solved the brownout issues that caused random resets in the earlier dual-rail prototype.

Offline Scheduling Fallback: Verified that scheduled feedings trigger on-time via the DS3231 RTC even with WiFi completely disconnected. Events are cached locally and uploaded to Firestore automatically upon reconnection.

The firmware is written in Arduino C++ and utilizes hardware button interrupts for manual feed override, alongside server-side Firestore polling filters to reduce unnecessary database reads and minimize Firebase costs.

3D Enclosure Design

The AquaPulse enclosure was designed to house all electronic and mechanical components in a single rugged, weather-resistant unit suitable for outdoor pond-side deployment. Below is the 3D render of the assembled device alongside a side cutaway view revealing the internal layout.

3D render of the AquaPulse Smart Fish Feeder enclosure

The enclosure features a translucent food hopper on top, allowing visual inspection of feed levels at a glance. The front panel includes a 16x2 I2C LCD displaying real-time status (time, hopper capacity, connectivity), a yellow status LED, and a red manual feed button for on-demand dispensing.

On the right side, a servo-driven actuator assembly with an adjustable lever arm connects to the dispensing auger, pushing pellets through the outlet chute into the pond. The green metallic casing provides durability while maintaining a compact footprint.

Side cutaway diagram showing internal component layout

The cutaway view reveals three functional zones:

Hopper & Sensing: An HC-SR04 ultrasonic sensor mounted above the pellet reservoir continuously measures fill level. The translucent hopper lid protects feed from moisture while allowing visual checks.

Dispensing Mechanism: A 28BYJ-48 stepper motor drives the dispensing auger through a geared wheel with an agitator arm to prevent pellet bridging. Portions are metered through the dispensing chamber and exit via the angled outlet chute.

Electronics Bay: The sealed lower compartment houses the ESP32 DevKit, DS3231 RTC module with coin-cell backup, ULN2003 stepper driver, and a power management board with isolated 5V rails for the motor and logic circuits.

Web Dashboard Interface

The AquaPulse web dashboard is built with React + TypeScript + Vite and connects to Firebase Firestore for real-time data synchronization. Farmers can monitor hopper levels, configure feeding schedules, and review historical feeding logs from any device.

Dashboard showing real-time hopper level (37%), feeder status, and manual controls

Feed history log with timestamps, quantities, source, and status

Key dashboard features include real-time hopper capacity percentage with visual gauge, configurable daily feeding schedules with portion sizes, event history with timestamps from both online and offline-triggered feeds, and low-feed-level push notifications to alert farmers before the hopper runs empty.

Conclusion

Successful Integration: Replaced the dual-board setup with a standalone ESP32, cutting serial communication lag and hardware cost significantly.

High Resilience: Standalone RTC scheduling and isolated power rails prove highly reliable for rural fish farming environments with unstable connectivity.

High ROI: Precise portion schedules reduce feed waste by up to 30%, significantly improving smallholder profits and aquaculture sustainability.
